# Current state

This repository serves one standalone Fumadocs documentation site for
MenuWright at `docs.menuwright.com`. The canonical authoring surface is the
flat MDX tree under `menuwright/`; `content/docs/` is derived output and is
regenerated by `node _migration/tools/run-migration.mjs` (deterministic, with
an unmapped-icon gate that fails generation).

The site brand is MenuWright's own (`#5D3EFB` accent, crossed-utensils mark in
`public/logo.svg` / `public/favicon.svg`); it carries no Axiom identity. The
product index doubles as the landing page: `next.config.mjs` rewrites `/` and
the clean page URLs (`/getting-started`, `/menu-matrix`, `/square`,
`/csv-import`, `/billing`, `/reports`, `/faq`) onto the `menuwright/*` routes
so the address bar stays product-prefix-free.

Deep pages render source-tree-derived related-guide wayfinding
(`lib/page-context.ts`), product identity accents, evidence-backed
`ProductPreview`/`ProcessFlow` visuals, and a fail-closed Mermaid fallback.
Contract tests assert navigation parity, per-page metadata, and unique
product accents (`npm run test:links`).

The docs-agent automation lives in the MenuWright product repo
(`MenuMakeover`): merged PRs draft MDX against `menuwright/**` and open draft
PRs into this repository (see `pipeline/docs-agent.yml`).

Re-establish repository facts with:

```bash
node _migration/tools/run-migration.mjs
npm run test:links
npm run links:check
npm run types:check
npm run build
npm run memory:check
```
